# النشر على خادمك (Node.js 22 + PostgreSQL + nginx)

الهدف: تشغيل المنصة على `2.24.60.36` بقاعدة `saad_albaqmi` حقيقية. هذه الحزمة **لم تُجرَّب على الخادم الفعلي** (لا أملك وصولًا إليه)؛ جرّبها أولًا وأرسل لي مخرجات أي خطأ.

## ما يلزمك قبل البدء
| المطلوب | لماذا |
|---|---|
| **نطاق** (دومين) يشير بسجل A إلى `2.24.60.36` | الدخول عبر Clerk وقراءة NFC والكاميرا تتطلب HTTPS، ولا شهادة بلا نطاق |
| حساب **Clerk** (نسخة Production) ومفاتيحه | المنصة تعتمد Clerk في الدخول؛ المفاتيح القديمة كانت مرتبطة ببيئة Replit |
| حساب **Resend** ونطاق مُرسِل موثَّق | دعوات الفريق ورموز OTP وإرسال أوامر الشراء |
| **مفتاح SSH** للدخول إلى الخادم | الأفضل من كلمة مرور root، ولا تُرسل كلمة المرور في محادثة |

## الخطوات
1. على جهازك: `node deploy/generate-secrets.mjs` — ينشئ `deploy/secrets.env` ويولّد كلمة مرور القاعدة وسرّي OTP والبطاقات.
2. افتح `deploy/secrets.env` واملأ القيم الفارغة (النطاق، Clerk، بريد المالك، Resend، مفتاح SSH). **الملف مُدرج في `.gitignore`؛ لا ترفعه ولا ترسله في محادثة.**
3. انسخ الملفين إلى الخادم:
   ```bash
   scp deploy/secrets.env deploy/setup-server.sh root@2.24.60.36:/root/
   ```
4. شغّل الإعداد (مرة واحدة، آمن للإعادة):
   ```bash
   ssh root@2.24.60.36 'bash /root/setup-server.sh /root/secrets.env'
   ```
   يثبّت Node 22 وpnpm وPostgreSQL وnginx، وينشئ القاعدة `saad_albaqmi` ومستخدمها، ويبني التطبيق، ويطبّق الترحيلات، ويفعّل خدمة systemd وجدار الحماية وشهادة HTTPS ونسخًا احتياطيًا ليليًا (14 يومًا).
5. احذف `/root/secrets.env` من الخادم بعد الانتهاء (الأسرار محفوظة في `/etc/saad-albaqmi` بصلاحيات مقيدة).
6. تحقّق: `curl https://دومينك/api/readyz` يجب أن يرجع `{"status":"ok","database":"ok"}`.

## التحديث لاحقًا
على الخادم: `saad-deploy` — نسخة احتياطية، ثم سحب الكود، ثم الترحيل، ثم البناء، ثم إعادة التشغيل، ثم فحص الصحة. فشل الترحيل يوقف العملية قبل إعادة التشغيل.

## بعد التشغيل
- سجّل الدخول بـ `ORG_OWNER_EMAIL` فتصبح المدير الأعلى.
- ابقَ على `OTP_FINANCE_REQUIRED=false` حتى تجرّب البريد ونافذة OTP، ثم غيّره في `/etc/saad-albaqmi/api.env` وأعد تشغيل الخدمة.
- لاستيراد بياناتك القديمة: `docs/legacy-import.md`.

## تحذيرات
- المستودع **عام**: لا تضع أي سر فيه. إن أرسلتَ كلمة مرور أو مفتاحًا في أي محادثة فغيّره.
- أوصي بتعطيل دخول root بكلمة مرور (`PasswordAuthentication no`) بعد التأكد من مفتاح SSH، وبإنشاء مستخدم إداري غير root.
